Cold review. Stop being the developer; be the release engineer.

Unnecessary complexity? Justified deps? Dead modules? Duplicate implementations?
Error paths? Resources released? Restoration reliable? Results truthful? Tests
meaningful? Platform limits visible? UI shows real state? Starts and stops?
Docs accurate? User data preserved?

Fix what you find. Then the final report: baseline, architecture, dependency
matrix, name decision, feature verdicts, bugs fixed, tests added, commands and
real output, root/Linux/manual limits, remaining issues, unverified behaviour,
diff summary. Don't claim zero bugs. Stop.
